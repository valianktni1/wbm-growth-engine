# Growth Engine V1.6.0 — Website to booked value

- Links a consenting anonymous website visit to the native Booking enquiry without email-address matching.
- Shows linked enquiries, accepted quotes, confirmed bookings and booked value by source, first page and tracked post.
- Measures all safe public WordPress marketing paths automatically; important configured paths retain friendly names.
- Verifies every returned visit against Growth's own hashed visit, source, campaign and page-view evidence.
- Excludes Booking test records and ignores invalid or stale attribution without interrupting normal Booking sync.
- Preserves Google Search Console, Admin password controls, business planning and all existing safety switches.

Booked value means current agreed work recorded by Booking, not cash received or profit.
